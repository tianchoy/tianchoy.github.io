## GoatCounter 计数口径（用户质疑"数据是否正确"）
- GoatCounter 默认只计 **visit** 而不是 pageview：同一访客（sessionKey = siteID + User-Agent + IP，内存保留 8 小时）对**同一路径** 8 小时内只 +1，刷新 10 次仍是 1。可在 Settings → Data collection → Sessions 关闭，关闭后每次 pageview 都算。
- 页脚读的 `/counter/*.json` 的 `count` 就是这个 visit 数（`count_unique` 与之相同），且有缓存（最长 4 小时），不会实时跳。
- 实测 2026-10-24 21:48：TOTAL=7、首页=4，说明在正常累计。

## 写作台下拉框换成自定义组件（web/ui.js + ui.css）
- 原生 `<select>` 在 macOS 上弹层无法美化，改为「按钮 + 自绘列表」：`enhanceSelect()` 把 select 包进 `.cs`，原生控件只做视觉隐藏（`.cs-native`，1px + opacity 0 + clip-path），**value / options / change 仍由原生承载**，所以 `catEl.value = x`、`innerHTML` 重建 option、既有 change/input 监听全都不用改。
- 关键实现三处：
  1. 实例上 `Object.defineProperty` 拦截 `value` / `selectedIndex` 的 setter → `syncLabel()`，这样程序赋值也能实时更新按钮文案；
  2. `MutationObserver`（childList + subtree + characterData + options 的 value/label/disabled）监听 option 重建 → `rebuild()`（分类、社交平台都是异步填充的）；
  3. `choose()` 必须**按原生顺序同时派发 `input` 和 `change`**——`/manage` 的筛选监听的是 `input`，只发 change 会筛选不生效。
- 交互：键盘 ↑↓/Enter/Esc/Tab、点空白处或页面滚动收起（全局监听只挂一次）、选项 > 8 项显示搜索框（站点的 63 个社交平台）、打开时按可用空间决定向上弹还是向下并设置 `menu.style.maxHeight`。
- 坑 1：`scrollIntoView` 之类滚动会在 open 后立刻触发 document scroll 监听把自己关掉 → `openedAt` 250ms 内忽略。
- 坑 2：`.cs-trigger` 原来 `line-height: 1.45` 比相邻输入框高 3.6px，改 `1.2` 后实测 36.2 vs 36，顶部对齐同像素。
- 坑 3：value 为空时不要把占位项（「选择分类…」）标成 `aria-selected` / 打勾，否则像已经选好了。
- 样式：`.cs-*` 一套，配色沿用 `--surface / --border / --accent / --shadow-md`，深浅色自动适配；`.filter-bar .cs { width: auto; min-width: 122px }` 保持与原 select 一致的收缩行为。

- **permalink 全错（最严重）**：`lib/posts.mjs` 直接拿文件路径拼链接，没复刻 Hugo 的 URL 规则。线上实际是 `public/posts/vue3/...`（小写、空格转 `-`、逗号去掉、`@` 保留），管理页/发布成功页给出的却是 `/posts/Vue3/DataTable 开发.../`，Vue3 等分类的「查看」链接全是 404。改为 `hugoSlug()`（小写 → 空白转 `-` → 只留 `\p{L}\p{N}\p{M}._+~@-`），baseURL 从 hugo.toml 读。**校验方法：拿 `/api/posts` 的每条 permalink 去 `public/` 里找 `index.html`，76/76 命中**。
- **分类名可路径穿越**：`createPost` 直接 `path.join(CONTENT_DIR, category)`，`category: "../../x"` 能把 md 写到 content/posts 之外。改为 `sanitizeDirName` + `resolveCategoryDir`，顺带解决「用户打 `vue3` 会新建目录、和 `Vue3` 撞同一个线上 URL」——建目录前按忽略大小写找现成目录。
- **并发发布**：两次点击/两个标签页同时保存会撞 `.git/index.lock`。`runDeploy` 改成 promise 队列串行，并加 5 分钟超时 kill。
- **本地服务没有同源保护**：任意网页都能 POST `http://127.0.0.1:4321/api/publish|/api/shutdown`（CSRF），DNS rebinding 还能伪装同源。加 `isLocalRequest()`：Host 必须是 127.0.0.1/localhost/[::1]，带 Origin 时也必须是本机。
- `resolveFile` 用 `startsWith` 判断包含关系（`/web-evil` 会被当成在 `/web` 里），且 `decodeURIComponent` 抛错会一路冒成 500。改 `path.relative` + try/catch，非法编码按 404。
- 请求体超限时 `req.destroy()` 让客户端只看到连接重置；改成回 413 JSON。
- `nowLocal()`/`nowStamp()` 写死 `+08:00`，改为按 `getTimezoneOffset()` 算。
- `server.listen` 没挂 error，端口被占直接抛栈；改为提示「写作台可能已在运行」并退出。
- `savePost` 遇到块状列表 frontmatter（`categories:\n  - diary`）只在原行替换，旧的 `- diary` 行留着 → 生成非法 YAML。现在替换/删除 key 时把紧随的 `- 项` 一起处理。
- 写作台「插入链接」按钮：没选中文字时插入的是空 `[](url)`（`[链接文字]` 那行 replace 是死代码），而且会全局替换文档里任何一处 `[链接文字]`。改成 setRangeText + 选中占位文字。
- `/publish` 启动时 `(titleEl.value ? contentEl : titleEl).focus()` 后面又跟一句 `titleEl.focus()`，草稿恢复时焦点被抢回标题。
- 预览 Markdown 的 `javascript:` 链接挡掉；`api()` 在服务已关闭时给出「重新双击写作台」而不是 `Failed to fetch`。
- `deploy.sh` 加 hugo 存在性检查；push 被拒（网页端改过文件）时自动 `pull --rebase --autostash` 重试一次。

## 第二轮全量代码体检（提交 c8f9d5f）

又读了一遍 publish-server.mjs / lib/* / web/* / layouts/* / deploy.sh，修掉 6 处：

- `lib/posts.mjs` `nowStamp()` 仍写死 `+08:00`（上一轮只改了 publish-server 的 `nowLocal()`）——编辑旧文章缺 date 时会写错时区偏移。改成按 `getTimezoneOffset()` 算。
- `lib/posts.mjs` `dateOf()`：`new Date("2023-09-14")` 按 UTC 零点解析，负时区下 `isoLocal()` 会把日期往前挪一天（列表显示 + 排序都错）。纯日期现在显式按本地时间构造（纽约时区实测：旧 2023-09-13 → 新 2023-09-14）。
- `lib/site-config.mjs` `saveAvatarFile()`：图片为空/超 12MB 抛的是普通 Error，路由层回 500。加 `userError()`（status=400），与 `lib/posts.mjs` 同名函数保持一致。
- 标签大小写去重：用户手填 `vue3`、自动补齐建议 `Vue3` 会写出两个只差大小写的标签（Hugo 归一成同一 term，标签页却显示两遍）。`cleanTags()` 按小写去重，`suggestTags()` 的 existing 判断与前端 `fillTags()` 的过滤同步改成大小写不敏感。
- `readCategories()` 只认 `categories: [a, b]` 内联写法，手改成块状列表（`categories:\n  - diary`）的文章分类会从写作台下拉里消失。补了块状列表分支。
- `deploy.sh`：`git pull --rebase --autostash` 冲突退出后仓库停在 rebase 中间态，之后每次发布都失败且报错难懂。失败时 `git rebase --abort` 再退出并给出手动处理提示。
