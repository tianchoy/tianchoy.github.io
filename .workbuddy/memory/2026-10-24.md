## 文章页：作者改成站点用户名 + 头像图标；标签终于显示（已上线 90d3945）

**作者名/头像**
- 根因：hugo.toml 没有 `[params.author]` 段，主题 `posts/single.html` 的 `$params.author | default .Site.Params.Author.name | default (T "author")` 全部落空 → 渲染出 i18n 的字面「作者」。
- 修法：站点侧新增 `layouts/posts/single.html`（复制主题 101 行后改 meta 段，Hugo 项目 layouts 优先于主题）。作者名回落链改为 `params.author → site.author.name → params.header.title.name → site.title → i18n`，即站点设置里的名字；头像取 `params.avatar → params.home.profile.avatarURL`，输出 `<img class="author-avatar">`，没有头像才退回 `fa-user-circle`。
- 样式：`_custom.scss` 里 `.post-author .author{display:inline-flex;align-items:center;gap:.35rem}`、`.author-avatar{1.15em 圆形; object-fit:cover; 灰色占位背景}`（实测 19×19px，和文字基线对齐）。
- 顺带给分类循环加了 `with ... GetPage` 保护（取不到页面时不再输出空 `<a>`）。

**标签不显示**
- 根因：`[taxonomies]` 只写了 `category = "categories"`，**这会顶掉 Hugo 默认的 tags**。于是 `Site.GetPage "/tags/博客"` 返回 nil，`single/footer.html` 里 range 两次只输出分隔符 `,`，页面上就剩一个标签图标 + 逗号。
- 修法：`[taxonomies]` 补 `tag = "tags"`。构建后 `public/tags/{博客,hugo,...}/` 全部生成，`/tags/` 列表页标题走 i18n 显示「所有标签」（分类页对应「所有分类」）。
- 附带：`.post-tags a` 原本继承出近黑色（rgb(22,18,9)），和左边分类的蓝不一致，`_custom.scss` 里改成 `$single-link-color`（#2d96bd），hover 加 opacity。

**验证**：线上文章页 200，作者 `特严赤傲` + `/images/profile.jpg`，标签链接 `/tags/博客/`、`/tags/hugo/` 均 200；CSS 指纹 `4458961c` 已含新规则。

## GoatCounter 计数口径（用户质疑"数据是否正确"）
- GoatCounter 默认只计 **visit** 而不是 pageview：同一访客（sessionKey = siteID + User-Agent + IP，内存保留 8 小时）对**同一路径** 8 小时内只 +1，刷新 10 次仍是 1。可在 Settings → Data collection → Sessions 关闭，关闭后每次 pageview 都算。
- 页脚读的 `/counter/*.json` 的 `count` 就是这个 visit 数（`count_unique` 与之相同），且有缓存（最长 4 小时），不会实时跳。
- 实测 2026-10-24 21:48：TOTAL=7、首页=4，说明在正常累计。
