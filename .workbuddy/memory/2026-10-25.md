## 3. SEO 优化（让更多搜索引擎收录）
- 主题已自带 canonical / Open Graph / Twitter Card / Description / JSON-LD（WebSite+BlogPosting），无需重复。补的缺口：

### 3 关闭服务
- 本地只有一个 Node 进程（publish-server.mjs，127.0.0.1:4321），它同时负责写作台四页 + 构建产物预览。点关闭服务 -> /api/shutdown -> process.exit(0)，整进程退出，所有功能一次性全停，没有别的独立服务。

### 4 写作台操作是否同步 GitHub
- 不是每次都同步：shouldDeploy() 看操作有没有带发布。写新文章点发布默认推送（除非勾仅存本地）；编辑已有文章保存只存本地不推送（编辑模式强制 localOnly）——这是最容易误会的点；删除只有勾删除后立即发布才推送；发布当前改动手动推全部本地改动。

## 6. 首页滚动条修复（13" MacBook 一屏展示）
- 现象：首页元素很少却有竖向滚动条。
- 根因：主题 `.wrapper` 本就是 `display:flex; flex-direction:column; min-height:100vh`，`main` flex:1、footer 贴底，整页高度本就等于一屏。但上一轮给 `.page.home` 又加了 `min-height: calc(100vh - 3.5rem)`，把内容区撑到近一屏，再叠加底部 footer（GoatCounter 统计+版权）→ 总高超一屏 → 滚动条。
- 修复：去掉 `.page.home` 的 100vh 约束，改让 `main` 在其高度（= 100vh - footer）内 `display:flex; align-items:center` 垂直居中 hero；`.page.home` 桌面端保留主题 `padding-top` 作兜底。
- ⚠️ 坑：主题用 libsass 编译 SCSS，**不支持 `:has()`**——最初用 `.wrapper:has(.page.home)` 写，libsass 直接丢弃整条规则且构建沿用旧缓存（hash 不变、旧规则还在）。改用普通类选择器：在 `themes/keepit/layouts/_default/baseof.html` 给 `.wrapper` 按 `.IsHome` 加 `home` 类（`<div class="wrapper{{ if .IsHome }} home{{ end }}">`），再用 `.wrapper.home` 选择。
- 验证：清 `resources/` 强制重编译后产物 hash 变化，`.wrapper.home main{display:flex;align-items:center;min-height:0}` 生效、旧 calc 消失、footer 仍在、`class="wrapper home"` 已输出。
