# 2026-10-25：社交图标对齐 + 文章管理分页 + SEO

## 1. 头像下社交图标统一尺寸与水平线（首页/关于页）
- 根因：主题 `.links` 用 `vertical-align:text-bottom` 混排 Font Awesome 字形（GitHub=fa-github-alt、饭否=fas fa-comment、Email=far fa-envelope 描边）与 simple-icons 注入的 `<svg>`（豆瓣，JS 拉取后替换，尺寸 1.25em×1em、蓝色 #448aff），基线/大小/颜色都不同。
- 修复：`assets/css/_custom.scss` 覆写 `.home-profile .links` 为 flex 横向居中、每个 `<a>` 固定 1.6rem 方块、`i`/`svg`/`img`/`.icon` 统一 1.25rem 正方形、hover 圆形底色。关于页复用 `home/profile.html`，一处同时覆盖两个页面。`assets/data/social.yml` 的 Email 由 `far fa-envelope`（描边）改 `fas fa-envelope`（实心），与另外三个视觉一致。

## 2. 文章管理页分页（每页 10 篇）
- `web/manage.html`：`PAGE_SIZE=10`，新增 `page` 状态、`pageCount()`/`pageNumbers()`(紧凑页码，>7 页用 1 … cur-1 cur cur+1 … total)/`renderPager()`；`render()` 改为按页切片渲染、`data-pick/data-del` 用「过滤后全局下标」保证翻页后仍指向同一篇；过滤变化重置到第 1 页；`checkAll` 只选当前页；翻页点击用 `#pager` 事件委托。`web/ui.css` 加 `.pager/.pager-num/.pager-gap/.pager-info` 样式。76 篇 → 8 页，分页数学已单测验证。

## 3. SEO 优化（让更多搜索引擎收录）
- 主题已自带 canonical / Open Graph / Twitter Card / Description / JSON-LD（WebSite+BlogPosting），无需重复。补的缺口：
  - `layouts/robots.txt`（覆写主题）：不再 `Disallow: /images/`（否则 OG 分享图/头像/favicon 抓不到），保留屏蔽采集型爬虫，末尾 `Sitemap: {{ .Site.BaseURL }}sitemap.xml`。
  - `layouts/partials/head/meta.html`（覆写主题）：加 `keywords` meta（首页取 params.keywords 数组、文章页取 tags，用 reflect.IsSlice 防字符串被 delimit 拆成字符码）+ RSS `<link rel="alternate" type="application/rss+xml">` 指向 `/posts/index.xml`（主题默认没输出）。
  - `hugo.toml`：`keywords` 改成数组；新增 `[params.verification]`（google/bing/baidu/yandex/pinterest 占位为空，填了主题 seo.html 才输出验证 meta）。
  - `.github/workflows/deploy.yml`：deploy 后新增一步 curl ping Google/Bing 的 sitemap 端点，主动通知爬虫（百度无公开匿名 ping，需在搜索资源平台手动提交 sitemap.xml）。


## UI 整体打磨（提交 1aeefbd）

用户要求：1 分页器底部留白；2 整体优化 UI；3 关闭服务是否停所有；4 写作台操作是否同步 GitHub。

### 1 分页器底部 padding（web/ui.css）
- .card 本身无内边距、分页器是卡片内最后一项，按钮贴着卡片下边。给 .pager 加 padding-bottom: 18px（margin-top 也调成 18px），底部留白补齐。

### 2 整体 UI 打磨（两块都过一遍，四个方向）
- 写作台：
  - :focus-visible 全局轮廓（.btn / a），键盘 Tab 才显示、鼠标点击不显示，交互一致性 + 可访问性。
  - .page 底部 padding 从 104px 降到 56px（那 104px 原本是给文章管理页底部 sticky 操作条留 clearance 的，但发布/设置/关于页没有操作条，白白空一大截）；.page.wide（仅文章管理）单独保留 104px。
- 公开博客：
  - 首页资料区（仅 .page.home，关于页不受影响）：加大头像/姓名/简介之间的留白，姓名字号 1.5rem/700；社交图标上方加一条 width:fit-content 居中细分隔线，首屏更有完成感。
  - 文章详情 .single .post-meta 底部加一条细分隔线，把元信息和正文分开，层级更清楚。
  - 文章行内 code（非代码块）加淡底色 + 圆角 + 字间距，和代码块风格统一（主题默认行内 code 是裸的）。
- 说明：两个样式系统（博客 KeepIt 主题 + 写作台 ui.css）原本已经比较完整，本轮是精修而非重构；未改博客主强调色（主题 teal）与写作台靛蓝的跨端色差，避免大改。

### 3 关闭服务
- 本地只有一个 Node 进程（publish-server.mjs，127.0.0.1:4321），它同时负责写作台四页 + 构建产物预览。点关闭服务 -> /api/shutdown -> process.exit(0)，整进程退出，所有功能一次性全停，没有别的独立服务。

### 4 写作台操作是否同步 GitHub
- 不是每次都同步：shouldDeploy() 看操作有没有带发布。写新文章点发布默认推送（除非勾仅存本地）；编辑已有文章保存只存本地不推送（编辑模式强制 localOnly）——这是最容易误会的点；删除只有勾删除后立即发布才推送；发布当前改动手动推全部本地改动。
