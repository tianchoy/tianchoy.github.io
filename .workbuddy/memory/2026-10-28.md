# 2026-10-28 工作日志

## 文章页「本页阅读量」显示 `-` 的修复
- 现象：文章详情页页脚「本站浏览 164 次」正常，但「本页阅读量」一直显示 `-`。
- 根因：昨日把分类 `diary` 改名 `随笔`，文章 URL 从 `/posts/diary/<slug>/` 变为 `/posts/随笔/<slug>/`；
  GoatCounter 历史阅读量仍记在旧 `diary` 路径（如 `/posts/diary/1988/` 实测 count=3），统计脚本按当前
  `location.pathname`（新路径）查 → 404/0。
- 次级 bug：GoatCounter 对无记录路径返回 HTTP 404 + `{"count":"0"}`，原 JS 只认 `r.ok`(200)，
  非 200 当 null，导致连真实 0 次也留 `-`，且该页无总量时整框可能被隐藏。
- 修复（`layouts/partials/stats.html`）：① 404 视作「0 次」正常展示；② 对当前页同时查「新路径 +
  旧 `/posts/diary/` 路径」并合计，改名前阅读量不再归零；③ 总量或本页任一有数就显示统计框。
- 验证：本地 hugo 构建后文章页脚本含 `replace(/\/posts\/随笔\//,"/posts/diary/")` 双路径合计；
  `1988` 显示 0+3=3，无历史文章显示 0（非 `-`）。
- 发布：`bash deploy.sh` 提交 `6c6663a` 推送 `3aecdef..6c6663a`（仅 stats.html 一处改动）。
- 备注：diary→随笔 的回退是硬编码，若将来再改分类名需同步更新该正则；旧 `/posts/diary/*` 外链暂无
  重定向（不影响阅读量显示，仅旧书签会 404），如需可后续加 Hugo aliases。

## 为旧 /posts/diary/* 地址补 Hugo aliases 重定向
- 背景：分类 diary→随笔 改名后，旧地址 `/posts/diary/<slug>/` 的外链/书签会 404。
- 操作：给 `content/posts/随笔/` 下全部 38 篇文章 frontmatter 追加 `aliases: ["/posts/diary/<slug>/"]`
  （slug 取文件名去 .md，与原 diary 期 URL 一一对应）。已存在则跳过（本次 0 跳过）。
- 验证：本地 hugo 生成 69 个 alias 重定向页（含本次 38），抽样 `public/posts/diary/1988/index.html`
  含 `<meta http-equiv="refresh" content="0; url=https://tianchoy.github.io/posts/%E9%9A%8F%E7%AC%94/1988/">`，正确跳转新地址。
- 发布：`bash deploy.sh` 提交 `e9cdfe1` 推送 `6c6663a..e9cdfe1`。
- 备注：旧 `diary` 期历史阅读量（记在 GoatCounter 旧路径）仍由 stats.html 双路径合计显示，与 aliases 互不冲突。

## 文章页「本页阅读量」仍显示 0 的二次修复
- 现象：上轮修复后，文章《1988》（导航 上=中元节/下=北泉寺）仍显示「本页阅读量 0 次」，但 `/posts/diary/1988/` 历史有 3 次。
- 排查：线上脚本已是含 diary 回退的新版（curl/接口均确认 diary/1988=3、CORS 头为 `*`、双斜杠也返回 3），
  逻辑推导应为 3。最终定位到根因——**部分浏览器对中文路径的 `location.pathname` 返回百分号编码形态**
  （`/posts/%E9%9A%8F%E7%AC%94/1988/`），而脚本正则 `/\/posts\/随笔\//` 用解码字面量匹配不上，
  导致 `legacyPage` 没被加入请求列表，只剩新路径的 0。
- 修复（`layouts/partials/stats.html`）：`var page = decodeURIComponent(location.pathname || "/");` 先解码再替换，
  编码/解码两种形态都能正确派生旧 diary 路径并合计。
- 验证：node 模拟两种 pathname 形态，1988 均得 `pageSum=3`；本地 hugo 构建产物含 `decodeURIComponent`。
- 发布：`bash deploy.sh` 提交 `6f09f8d` 推送 `e9cdfe1..6f09f8d`。
