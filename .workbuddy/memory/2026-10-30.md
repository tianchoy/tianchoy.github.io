### Dart Sass 安装（关键坑）
- **Hugo 的 dartsass 需要原生 Dart Sass 二进制，不接受 npm 的 `sass`（Node JS 包装版）**：用 `node_modules/.bin/sass` 构建会报 `TOCSS-DART: got unexpected EOF when executing "sass"`。
- 本机可行的原生二进制来自 ruby gem `sass-embedded`：
  `~/.rvm/gems/ruby-3.3.5/gems/sass-embedded-1.83.4-arm64-darwin/ext/sass/dart-sass/sass`（1.83.4）。
- 已 `ln -sf` 到 **`/opt/homebrew/bin/sass`**（该目录可写），本机 deploy.sh / 写作台.app（launcher PATH 含 /opt/homebrew/bin）都能找到。
- `npm i -D sass` 装过又 `npm rm sass` 卸载；`package-lock.json` 与 `node_modules` 已删，`package.json` 保持无依赖。
- `deploy.sh` 增加：`command -v sass` 找不到时把 `/opt/homebrew/bin` 加进 PATH。
- `写作台.app/Contents/MacOS/launcher`：PATH 注释说明 `/opt/homebrew/bin/sass` 为原生 dart-sass。
- `.github/workflows/deploy.yml`：新增 `Install Dart Sass` 步骤，**下载官方原生包** `dart-sass-1.83.4-linux-x64.tar.gz` 解压到 `$RUNNER_TEMP` 并写入 `$GITHUB_PATH`（不能用 `npm i -g sass`，那是 JS 版）。
