- 本地 Hugo 二进制：`/opt/homebrew/bin/hugo`（v0.168.0 extended，必须 extended 才能编译主题 SCSS）。brew 因沙箱/TCC 装不上，二进制为手动下载安装。**线上发布版本由 `deploy.yml` 的 `hugo-version` 决定（当前 0.169.0），与本地二进制可不同；升级 Hugo 改 deploy.yml 即可（2026-10-29 验证：v0.169.0 无破坏性变更）。注意：本机沙箱代理会**截断大文件下载**（GitHub release 资产单连接最多 ~2.88MB，curl 直连 502、gh 也被截），**本地 Hugo 二进制无法在此环境自动下载升级**，需用户本机手动装（brew upgrade hugo / 下载 pkg 装到 /usr/local/bin，再把 /opt/homebrew/bin/hugo 替换成新版 extended 二进制）。** v0.169.0 构建仅 WARN（非错误）：`css.Sass` 的 **libsass 已弃用**（未来某版本会彻底移除，届时 SCSS 编译会失败，需迁 dartsass）、`.Site.LanguageCode`/`.Site.Data` 弃用（KeepIt 主题内使用）；当前均不影响发布。→ **libsass→dartsass 已完成迁移（2026-10-30，用户明确要求）**：dartsass 由站点覆写 `layouts/partials/head/link.html` 在 `toCSS` 的 options 加 `"transpiler":"dartsass"` 开启。**主题 38 个 SCSS 的正确位置是 `themes/liubai/assets/css/`**（含 `_custom.scss`，随主题 vendored）；当天曾误复制到站点根 `assets/css/`，已纠正迁回主题并删除站点根 `assets/css/`。主题的 layouts/static/i18n/lib 等仍保留，站点依赖其渲染。**dartsass 必须用原生 Dart Sass 二进制，npm 的 `sass`（Node JS 包装版）会报 `TOCSS-DART: got unexpected EOF`**：本机原生二进制来自 ruby gem `sass-embedded-1.83.4`（`~/.rvm/gems/ruby-3.3.5/gems/sass-embedded-1.83.4-arm64-darwin/ext/sass/dart-sass/sass`），已 `ln -sf` 到 `/opt/homebrew/bin/sass`（deploy.sh / 写作台 launcher 的 PATH 都含 /opt/homebrew/bin）；CI 在 `deploy.yml` 用 `Install Dart Sass` 步骤下载官方 `dart-sass-1.83.4-linux-x64.tar.gz` 解压到 `$RUNNER_TEMP` 并写入 `$GITHUB_PATH`。dartsass 产物与原 libsass **规则/声明/选择器数完全一致（871/2161/817）**，差异仅 hex↔rgb 小数、`0.9`↔`.9`、`"\A"`↔`"\a"` 等等价格式，视觉一模一样（CSS 指纹 `bb81cd91…` 不变）。仍有 slash-div、color 函数 deprecation WARN（Dart Sass 2.0 才硬错误）。
- 文章 frontmatter 约定：title / date / categories / draft / tags。**每篇固定 5 个 tag**（2026-10-24 起全站统一）。**tag 名别用小写开头的技术名或带 `_`/`-` 的词**：Hugo 用 AP 风格 title-case 显示 `$tag.Title`，`defineProps`→DefineProps、`npm`→Npm、`miot-plugin-sdk`→Miot-Plugin-Sdk；`titleCaseStyle = "Go"` 更糟（`Node.js`→Node.Js），别改。这类一律用中文词。**`[taxonomies]` 必须同时写 `category` 和 `tag`**——只写 category 会把 Hugo 默认的 tags 顶掉，文章底部标签会渲染成空（`Site.GetPage "/tags/x"` 返回 nil，只剩图标和逗号）。已启用 `/tags/` 与 `/categories/`（标题走 i18n「所有标签 / 所有分类」）。
