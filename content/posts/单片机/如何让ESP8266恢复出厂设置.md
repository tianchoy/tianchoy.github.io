1，安装python，2.7或者更高版本
2，运行：
```bash
get-pip.py
```
3，运行：
```bash
pip install esptool
``` 
4，运行的指令：
```bash
esptool.exe --port COM3 erase_flash
```
如果报错,就改成这样的命令试试：

```bash
esptool.py.exe --port COM3 erase_flash
```
